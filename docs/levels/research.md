# Level 7 · Research <span class="pm-badge pm-badge-research">Research</span>

**You work at the edge of what Python can do — building compilers, modifying the interpreter, and engineering new language features.**

---

## What you'll learn at this level

- [x] Emit LLVM IR and MLIR from Python
- [x] Build a tracing JIT compiler from scratch
- [x] Rewrite Python bytecode at runtime
- [x] Fork and modify the CPython interpreter
- [x] Change Python's grammar and PEG parser
- [x] Build a bytecode virtual machine
- [x] Work with HPC clusters using MPI4py
- [x] Implement quantum algorithms with Qiskit
