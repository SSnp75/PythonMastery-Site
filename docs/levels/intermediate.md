# Level 3 · Intermediate <span class="pm-badge pm-badge-intermediate">Intermediate</span>

**You write expressive, reusable Python using decorators, generators, type hints and functional patterns.**

---

## What you'll learn at this level

- [x] Write and stack decorators with `functools.wraps`
- [x] Build memory-efficient pipelines with generators and `yield from`
- [x] Manage resources reliably with context managers
- [x] Annotate code fully with type hints and `Protocol`
- [x] Use `map`, `filter`, `reduce` and `functools` patterns
- [x] Work with NumPy arrays and Pandas DataFrames
- [x] Visualise data with Matplotlib and Seaborn
