# Level 4 · Proficient <span class="pm-badge pm-badge-proficient">Proficient</span>

**You build production-ready systems — APIs, async services, ML pipelines, and concurrent applications.**

---

## What you'll learn at this level

- [x] Build REST APIs with FastAPI or Flask
- [x] Write `async/await` code with `asyncio`
- [x] Use `threading` and `multiprocessing` for parallel work
- [x] Query databases with SQLAlchemy and ORMs
- [x] Scrape the web with BeautifulSoup and Playwright
- [x] Train and evaluate ML models with Scikit-Learn
- [x] Deploy Python apps to the cloud
