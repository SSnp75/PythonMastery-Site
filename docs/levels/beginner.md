# Level 1 · Beginner <span class="pm-badge pm-badge-beginner">Beginner</span>

**You can write simple scripts, understand Python syntax, and work with basic data structures.**

---

## What you'll learn at this level

By the end of Level 1 you can:

- [x] Write, run and debug a Python script
- [x] Use all basic data types — int, float, str, bool, None
- [x] Control program flow with `if`, `elif`, `else`, `for`, `while`
- [x] Define and call functions with parameters and return values
- [x] Work with lists, tuples, sets and dictionaries
- [x] Read and write files
- [x] Write clean, Pythonic code from the start
