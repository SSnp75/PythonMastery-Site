# Level 2 · Competent <span class="pm-badge pm-badge-competent">Competent</span>

**You can build small real-world projects using OOP, handle errors properly, and organise code into modules.**

---

## What you'll learn at this level

- [x] Organise code into modules and packages
- [x] Write classes with inheritance, encapsulation and polymorphism
- [x] Handle exceptions correctly with `try/except/finally`
- [x] Debug programs with `pdb` and logging
- [x] Use the Python Standard Library effectively
- [x] Work with Unicode, text and regular expressions
- [x] Use `@dataclass` for clean data containers
- [x] Write powerful list, dict and set comprehensions
