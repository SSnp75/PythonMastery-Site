# Level 5 · Advanced <span class="pm-badge pm-badge-advanced">Advanced</span>

**You understand Python from the inside — the object model, memory management, bytecode and performance bottlenecks.**

---

## What you'll learn at this level

- [x] Write descriptors that power `@property` and ORMs
- [x] Create metaclasses that control class creation
- [x] Read and understand Python bytecode with `dis`
- [x] Understand CPython's reference counting and GIL
- [x] Profile memory and CPU with precision
- [x] Speed up Python with Cython, Numba and Rust extensions
- [x] Implement distributed system patterns
