## Your Learning Path

Not sure where to start? Answer these:

=== "I'm brand new to Python"
    Start here → [Python Basics](core/beginner/python-basics.md)

    Then follow the **🐍 Core Python** track from Beginner → Competent → Intermediate.

=== "I know basics, want to build things"
    Start here → [Web Frameworks](web/proficient/frameworks.md) or [Scikit-Learn](data/proficient/scikit-learn.md)

    Pick the **🌐 Web & APIs** or **📊 Data & AI** track.

=== "I build things but want to go deeper"
    Start here → [Decorators](core/intermediate/decorators.md) → [Asyncio](systems/proficient/asyncio.md)

    Then tackle **⚙️ Performance** track.

=== "I want to understand Python's internals"
    Start here → [Bytecode](core/advanced/bytecode.md) → [CPython Internals](core/advanced/cpython-internals.md)

    Then move into **🔬 Research & Compilers** track.
