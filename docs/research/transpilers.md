## What is a transpiler?

A source-to-source compiler that translates code from one language to another at the same abstraction level.

```
Python source → AST → Code generator → Rust/C/JS source
```

---

## Existing examples

- **Cython** — Python → C
- **Transcrypt** — Python → JavaScript
- **mypyc** — typed Python → C extensions
- **Codon** — Python → native (LLVM)
