# 🐍 Core Python Track

**Master the language itself — from your first variable to the CPython interpreter.**

This is the foundation track. Everything else on this site builds on what you learn here. Even if you're on the Web or Data track, you'll keep returning to Core Python as you go deeper.

---

## Track Overview

| Level | Topics | Goal |
|---|---|---|
| Beginner | 6 | Write and run Python scripts confidently |
| Competent | 8 | Build real programs with OOP and modules |
| Intermediate | 6 | Write expressive, professional-grade Python |
| Advanced | 10 | Understand Python from the inside out |

## Cross-track connections

When you finish Intermediate, these tracks open up naturally:

- **⚙️ Performance** — you understand decorators and generators; now make them fast
- **🌐 Web** — OOP and type hints are prerequisites for FastAPI
- **📊 Data** — functional patterns directly apply to NumPy and Pandas pipelines
