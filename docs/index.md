## The 7 Levels at a glance

Every topic on this site is tagged with one of these levels so you always know where you stand.

| Level | Name | What you can do |
|---|---|---|
| 1 | **Beginner** | Write simple scripts, understand syntax, use basic data structures |
| 2 | **Competent** | Build small projects, use OOP, handle errors, work with modules |
| 3 | **Intermediate** | Use decorators, generators, type hints, write tests |
| 4 | **Proficient** | Build APIs, use asyncio, work with databases and web frameworks |
| 5 | **Advanced** | Understand metaclasses, CPython internals, tune performance |
| 6 | **Expert** | Design systems, implement security, architect at scale |
| 7 | **Research** | Build compilers, modify the interpreter, do language engineering |

[See full levels breakdown →](levels/index.md)

## How this site works

!!! tip "Guided vs Free Explore"
    You can use this site in two ways:

    **Guided** — Pick a track, follow it top to bottom. Each page tells you what to read before and after.

    **Free Explore** — Use the search bar or roadmap to jump to any topic directly.

    This site is built alongside active learning. Pages marked **Coming Soon** will be filled in as topics are studied. The structure is complete — the content grows with time.
