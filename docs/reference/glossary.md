# 📖 Glossary

Python terms defined in plain language. Use Ctrl+F to search.

---

**ABC** — Abstract Base Class. A class that can't be instantiated, used to define interfaces.

**Bytecode** — The low-level instructions Python source is compiled to before execution.

**Closure** — A function that remembers variables from its enclosing scope even after that scope has finished.

**Coroutine** — An async function (defined with `async def`) that can be paused and resumed.

**Decorator** — A function that wraps another function to modify its behavior. Applied with `@`.

**Descriptor** — An object with `__get__`, `__set__`, or `__delete__` that controls attribute access.

**Duck typing** — "If it walks like a duck and quacks like a duck..." — using objects based on behavior, not type.

**EAFP** — Easier to Ask Forgiveness than Permission. Try it and handle the exception.

**Generator** — A function that uses `yield` to produce values lazily, one at a time.

**GIL** — Global Interpreter Lock. Allows only one thread to execute Python bytecode at a time.

**Iterable** — Any object you can loop over (`list`, `dict`, `file`, generators, etc.).

**Iterator** — An object with `__next__()` that produces values one at a time.

**LBYL** — Look Before You Leap. Check conditions before acting (opposite of EAFP).

**Metaclass** — A class of a class. Controls how classes are created.

**MRO** — Method Resolution Order. The order Python searches for methods in inheritance hierarchies.

**Mutable** — Can be changed after creation (lists, dicts). Opposite: immutable (tuples, strings).

**PEP** — Python Enhancement Proposal. The process for proposing changes to Python.

**Protocol** — A typing construct for structural subtyping (duck typing with type hints).

**Unpacking** — Extracting values from sequences: `a, b, c = [1, 2, 3]`.

**Yield** — Keyword that makes a function a generator. Pauses execution and produces a value.
